# Features

Feature descriptions, use cases, and user interactions.

## 🎯 What You'll Find

Comprehensive documentation of:
- **Task Management** - Create, edit, complete, delete, and search tasks
- **Event Management** - Manage calendar events with recurring options
- **Planning Views** - Daily timeline, weekly buckets, monthly heatmap
- **Recurring Items** - Daily, weekly, monthly, and custom recurrence patterns
- **Capacity Visualization** - See workload at a glance
- **Navigation Patterns** - How to move between views and select dates
- **Data Categories** - Organize tasks by learning, work, health, personal

## 💡 Use Cases

Learn how PlanAware helps with:
- Weekly planning and prioritization
- Balancing multiple projects and courses
- Tracking estimated time for tasks
- Understanding your capacity and workload
- Managing recurring commitments
- Visualizing upcoming deadlines
