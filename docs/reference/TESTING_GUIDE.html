🏗️ Architecture Overview

Desktop (Phone Mockup)

PhoneFrameWrapper (isMobileMode=false)
  ├─ main.page-shell
  ├─ div.phone-frame
  │  ├─ StatusBar (10:37 📶 100%)
  │  └─ section.app-card
  │     └─ App Content
  └─ Rounded corners + shadow effect

Mobile (Full Screen)

PhoneFrameWrapper (isMobileMode=true)
  ├─ div.mobile-app-shell
  │  └─ App Content
  └─ Full viewport, no frame, no status bar

📊 Detection Logic

The app uses a multi-factor detection strategy:

Factor 1: PWA Mode

navigator.standalone
or
display-mode: standalone

Factor 2: User Agent

Detects mobile OS:
iOS, Android, etc.

Factor 3: Viewport

Screen width
< 768px (mobile)

Factor 4: Override

VITE_MOBILE_MODE
environment variable

⚠️ Important Notes

  • The phone frame mockup is ONLY for desktop browser viewing
  • Actual mobile installations will NOT show the phone frame
  • The status bar on desktop is simulated (not OS chrome)
  • Real devices use their native status bar
  • Responsive layout activates at <768px viewport width
